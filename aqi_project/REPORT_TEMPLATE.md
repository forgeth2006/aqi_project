# Report outline (fill in numbers from outputs/summary.txt)

1. **Title and objective** – forecast AQI and find which pollutant drives it.
2. **Data** – source, city, period, number of rows, variables.
3. **Data cleaning** – duplicates removed, missing values interpolated, outliers capped.
4. **EDA** – frequency table + bar/pie charts, histogram, skewness and kurtosis, heatmap.
5. **Estimation** – mean AQI with 95% confidence interval.
6. **Regression** – linear, polynomial, multiple (R², adjusted R², RMSE table); VIF, Breusch-Pagan, Cook's distance.
7. **Classification** – logistic regression (accuracy, Gini, Hosmer-Lemeshow) vs CART tree.
8. **Time series** – moving average, exponential smoothing, ARIMA; RMSE/MAPE; 6-month forecast.
9. **Conclusions** – strongest predictor, seasonal pattern, best model, limitations.
